# Creating a New Character

In Skyrim Unification Project, RaceMenu is set to use High Poly Head by default.  The vanilla brows and beards are hidden and you should only see ones compatible with HPH.  There are many options added from mods, including regular and SMP KSHair.  SMP Vanilla Hair Remake will override the vanilla hair options.

{: .important}
>Note: In some cases there may be a memory leak during RaceMenu.  It is recommended that once you finish your character creation, and finish the following Mod Menu step, you save the game, close the game completely, and then load that save, to clear any memory issues and avoid a crash.  This will also make sure you don't lose all your hard work creating the character appearance.


# Setting Up Mod Menus

After exiting Racemenu, you will get a notification "Please keep the menu closed while MCM configuration finishes."  This indicates that MCM Recorder is running the automatic configuration.

When it finishes, it will display a notification "MCM configuration complete.  When LOTD has finished counting displays, please use MCM Recorder to run SUP_MCM_Manual."  This step is required because LOTD's MCM cannot be configured to set the display count delay until it finishes its counting process.

When LOTD is finished, it will display "Museum list building complete." at which point you should open the MCM list, go to MCM Recorder, and execute SUP_MCM_Manual.  This can be done after choosing alternate start; you don't have to wait in the prison.

# Choosing An Alternate Start

Interact with the Statue of Mara to select an alternate start, then sleep in the bed.  Make sure to equip any granted equipment, it doesn't always auto-equip.

If you wish to play the vanilla start, select "I was caught crossing the border", but we recommend as a default start "I was camping in the woods" which places you nearby Helgen.

If you have chosen any start other than the vanilla one, you will need to visit Helgen to progress before starting the main quest.

# Wintersun Religion Prompt

When you first enter an exterior (leaving a building, or being placed outside by your alternate start) you will be prompted for your Wintersun worship preferences.  You can pick a starting deity, or choose None and either forgo the worship system or wait to discover a shrine or Daedric influence naturally during gameplay.

# SunHelm

After the first time you sleep in a bed, SunHelm will initialize.  Usually this will be during Alternate Start.  Note: There will be a warm/cold icon in the top right, currently we are unable to default it to another location or disable it by default.  You can use the MCM to move it, or turn it off.

If you do not want to use SunHelm's survival features, or only part of them, you may disable any or all in its MCM.  This is the recommended approach rather than trying to disable the plugins, as patches depend on them.

# A Note on Brightness and Quick Light

This list uses Lux for lighting, and may be darker than you are used to, especially in caves and dungeons.  In those locations you may wish to take advantage of Quick Light (hold E / L key) for a short-range light source on your character.  Torches or light spells can be used for a larger light.

# Dynamic Activation Key

Dynamic Activation Key allows many additional interactions when *holding* the Activate (E) key.  Some additional interactions are accessed by *Shift* + Activate such as Read/Take books.
