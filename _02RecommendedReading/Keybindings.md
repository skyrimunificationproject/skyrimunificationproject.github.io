## Hotkey Reminder

{: .important}
>Keybindings can be shown and hidden at any time by pressing `F11`.

## Changes to Default Keys

SUP moves the default keys for sprint, sneak, and walk/run to allow easier dodging.

Sprint is moved to LShift, Sneak is moved to LCtrl, and LAlt is used to dodge.

Walk/Run has been moved to CapsLock.

## Debug Menu

{: .important}
>We include Debug Menu even on the regular game profile because it's an invaluable tool for diagnosing issues.  It is accessed with F1 and defaults to turning on navmesh display.  If you enable it by accident, click the Navmesh button on the right side, then (Esc) to exit to turn it off again.  Expert users can use this to provide screenshots showing navmesh (runtime) broken edges or misplaced XMarkers to speed up solving issues.
